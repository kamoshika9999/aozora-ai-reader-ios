3. 詳細

3.1 端末内に保存される情報

本アプリは次の情報を利用者の端末内（WebView の localStorage / IndexedDB、および Android アプリのプライベート領域等）に保存します。

  • 音声エンジン設定（ハイブリッド／VOICEVOX／標準 TTS）、話速、テーマ、配役プロファイル
  • ダウンロードした小説メタデータ・本文、合成済み音声キャッシュ（端末内保護のための暗号化を含む場合があります）
  • バックグラウンド再生解放の有効期限、広告表示間隔に関するカウンタ
  • 利用規約・著作権ポリシーへの同意フラグ
  • 利用者がブロックした作品・作者の一覧（端末ローカル。他端末へ自動同期しません）

これらはアプリ機能の提供・高速化・オフライン利用のために用い、開発者のサーバへ自動アップロードされません。

3.2 青空文庫へのアクセス

利用者が青空文庫作品の検索・作品表示・保存を行うと、本アプリは青空文庫の公式アーカイブ・GitHubミラー等へ通信します。 サイト側で記録されるアクセスログ等は、青空文庫の利用指針に従います。 外部Web小説投稿サイトへの直接クローリング機能は提供しておらず、本アプリは成人向け（R18）ドメイン／パスへのアクセスを遮断する設計です。

3.3 外部 AI（Gemini 等）— 任意

利用者が設定画面で API キーを入力し、クラウド LLM を有効にした場合に限り、登場人物判定・配役解析のために本文の一部が当該 API へ送信されます。 API キーは端末内に保存され、開発者が収集・保管することはありません。 ローカル／ルールベース解析のみを用いる場合、この送信は行われません。 LLM 提供者側の取扱いは各社ポリシー（例: Google Privacy Policy）をご確認ください。

3.4 広告（Google AdMob）

本アプリは Google Mobile Ads SDK（AdMob）により、バナー・インタースティシャル・リワード広告を表示します。 Google は広告配信・不正防止・効果測定のため、広告 ID（Advertising ID）、IP アドレス、端末情報、操作イベント等を取得する場合があります。 詳細: https://policies.google.com/privacy / AdMob ヘルプ

利用者は端末の設定（Google 設定 > 広告、または Android のプライバシー設定）から広告のパーソナライズを制限できます。 リワード広告の視聴は任意であり、視聴完了によりバックグラウンド再生時間の解放などアプリ内特典を付与します。

3.5 UGC 通報・ブロック

本アプリは第三者作成の小説（UGC）を扱います。不適切コンテンツへの対応として次を提供します。

  • 通報: アプリ内からメール下書きを作成し、窓口 hosokawamamoru.mh@gmail.com へ送信できます。送信内容には作品識別子、題名、作者名、理由、任意コメントが含まれます。送信は利用者のメールアプリ経由であり、公開通報サーバへの自動投稿ではありません。
  • ブロック: 端末内リストに保存し、検索結果等から非表示にします。開発者サーバへは送信されません。

3.6 共有・エクスポート

共有機能を用いる場合、作品タイトルおよび公開ページ URL 等のメタデータを共有シートへ渡すことがあります。 本文全文や生成音声ファイルを、アプリの標準機能としてインターネット上へ自動公開・再配布することはありません。

4. 開発者が収集しないもの

  • 氏名・住所・電話番号などのアカウント登録情報（本アプリに会員登録機能はありません）
  • 端末内キャッシュの常時リモート監視
  • 利用者データの販売・貸与

ただし、利用者が通報メールを送信した場合、そのメール本文・送信元アドレスは開発者が受領・対応のために取り扱います。

5. 第三者提供

開発者は、法令に基づく場合または利用者の明確な指示（通報メールの送信、任意の外部 LLM 利用、広告 SDK による Google への送信）を除き、個人データを第三者に提供しません。 AdMob / LLM / 小説サイトへの送信は、各サービスの運営者の管理下で処理されます。

6. 子どものプライバシー

本アプリは 13 歳未満の児童を対象として設計していません。13 歳未満から意図的に個人情報を収集しません。 成人向けコンテンツはアプリ側で遮断しますが、インターネット上の全コンテンツの安全性を保証するものではありません。保護者の監督のもとでご利用ください。

7. セキュリティ

外部通信には HTTPS 等の暗号化を用います。端末内データは OS のアプリサンドボックス内に保存し、音声キャッシュ等については端末内での保護強化（暗号化）を行う場合があります。 ただし、インターネット通信および端末紛失・不正ルート化等のリスクを完全に排除することはできません。

8. データの確認・削除

  • 端末内データ: アプリの設定内「ストレージ管理」等からキャッシュ・保存作品・ブロック履歴を消去できます。アプリのアンインストールでも端末内データは削除されます。
  • 通報メール: 窓口へ削除・訂正を希望する場合は、該当メールの特定に必要な情報を添えてご連絡ください。
  • 広告 ID: 端末設定からリセット／オプトアウトできます。
  • 外部 LLM API キー: 設定画面から削除できます。

9. Google Play データセーフティ申告との関係

Play Console の Data Safety フォームは、本ポリシーと次の方針で整合させます。

  • 収集する可能性があるデータ: 端末・その他 ID（広告 ID）、アプリ操作（広告関連）、（任意）その他（通報メール内容）
  • データ共有: Google（広告）／利用者が選択した LLM 提供者／利用者が送信した通報メールの宛先（開発者）
  • 暗号化通信: はい（転送中）
  • アカウント作成: なし
  • 子ども向け: いいえ
